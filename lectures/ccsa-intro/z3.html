The Zuse Z3 — the first programmable computer ran on relays

Berlin, 1941: a machine of 2,400 clacking telephone relays reads its program from a strip of punched film and computes in binary floating point. Punch a tape below, feed the keyboard queue, and press ▶ Run — then flip on tape loop to see how Zuse iterated without a single branch instruction: with scissors and glue.

The Machine

1941 · Konrad Zuse · Berlin 2,400 electromagnetic relays
The first working programmable, fully automatic digital computer. Binary floating-point arithmetic (22-bit words: sign · 7-bit exponent · 14-bit mantissa) and Boolean logic, clocked at roughly 5–10 Hz. Destroyed in a Berlin air raid, 1943.
How it was programmed Programs were holes punched into discarded 35 mm movie film — one 8-bit instruction per frame, pulled frame by frame through a reader. No conditional branch existed: to loop, operators glued the tape ends into a physical ring. Numbers went in on a decimal keyboard; answers lit up on a lamp display.
What it actually solved Zuse was a civil engineer sick of grinding through structural formulas by hand. At the German Aeronautical Research Institute (DVL) his machines ran aerodynamic and wing-flutter calculations — evaluating the same formula over and over for tables of inputs.

Luread a number from the keyboard into a register

Pr zload memory word Zz — the first Pr fills R1, the next fills R2 (the Z3 auto-routed loads)
Ps zstore R1 into memory word Zz (R1 clears)
Ls1R1 := R1 + R2
Ls2R1 := R1 − R2
LmR1 := R1 × R2
LiR1 := R1 ÷ R2
LwR1 := √R1

After any arithmetic op, R2 clears. There is no jump, no branch, no halt — the program is the physical length of the film.

Simplifications — where this differs from the real Z3

  • 16 memory words instead of 64. The real store held 64 floating-point words in 1,400 of the 2,400 relays.
  • Simplified register plumbing. We route loads as “R1 if free, else R2,” clear R1 on Ps/Ld, and clear R2 after every arithmetic op. The real routing achieved the same effect with more hardware nuance.
  • Adjustable speed. The real machine ran at ~5–10 Hz: about 0.8 s per addition and ~3 s per multiplication. Our slider is a luxury Zuse never had.
  • The tape was real 35 mm movie film (often discarded newsreel stock). Our 8-hole frames use a consistent 2-bit-class + 6-bit-payload encoding in the spirit of the original coding; some exact historical hole patterns differed.
  • Decimal ↔ binary conversion is instant here. The real Z3 genuinely performed this conversion itself — decimal keyboard in, binary floating point inside, decimal lamps out — but it took machine time.

Floating point, in relays

Zuse put scientific notation in hardware — sign, exponent, mantissa — two years before anyone else was even close. Notice the trade you can see in the relay view: a huge range of magnitudes, but only 14 mantissa bits of precision. That is exactly the same bargain IEEE 754 strikes on your GPU today, just with more bits.

No branch instruction = no “if”

The Z3 cannot compare two numbers and choose a path — there is no conditional branch at all. The glued tape loop is a while(true) whose exit condition is “the input queue ran dry.” Control flow was literally scissors and glue. Every if in your code is a luxury the first programmable computer never had.

5–10 Hz vs 5 GHz

A modern core clocks about a billion times faster than the Z3’s relays. Yet watch the reader gantry: fetch an instruction, execute it, advance, repeat. That fetch–execute rhythm is identical to what your CPU does — which is the lecture’s core distinction: architecture outlives implementation. Relays, tubes, transistors — the rhythm survives them all.
