1 · Quiz answer key — quiz.html, 12 questions

Correct answer listed first in green; each distractor is annotated with the misconception it probes. Use the annotations for post-quiz debrief — the wrong answers are where the teaching is.

  1. What is computer architecture?
    • The programmer-visible blueprint of the system: the ISA (instructions, opcodes, addressing modes, registers), memory organization, and I/O mechanisms.
    • The physical circuits, gates and chip layout — confuses architecture with organization (the classic swap).
    • The case, motherboard and cabling of a computer — "architecture = hardware you can touch" misconception.
    • The clock speed and benchmark scores of a CPU — mistakes a performance metric for the design specification.
  2. What is computer organization?
    • How the system is physically realized: microarchitecture, RTL, circuits and gates — it changes with IC technology while the architecture stays fixed.
    • The set of instructions a programmer can use — the same swap in the other direction (that's architecture/ISA).
    • How the operating system schedules processes — confuses hardware organization with OS resource management.
    • How files and folders are arranged on disk — naive everyday reading of the word "organization".
  3. In Babbage's Analytical Engine, the Mill and the Store correspond to today's…
    • CPU and memory.
    • I/O devices and the system bus — knows the von Neumann parts list but maps the wrong ones.
    • ALU and control unit — both live inside the CPU — partial understanding of the hierarchy.
    • Hard disk and RAM — the Store held working numbers (memory), not archival storage.
  4. Ada Lovelace is called the first programmer because…
    • Her 1843 Note G contained the first published program — an algorithm (Bernoulli numbers) for the Analytical Engine — and she saw computing going beyond numbers.
    • She built the Analytical Engine with Babbage — the "she merely assisted Babbage" myth; conflates building hardware with writing software.
    • She invented the punched card — confuses her with Jacquard/Hollerith.
    • She programmed ENIAC during WWII — a century off; conflates her with the six ENIAC programmers.
  5. Why does the Jacquard loom (1801) matter to computing?
    • Its punched cards stored binary instructions — hole / no-hole — that controlled the machine: instruction storage before any computer existed.
    • It performed arithmetic calculations — it wove cloth; it computed nothing — the point is the instruction encoding.
    • It was the first electronic machine — "old + important = electronic" anachronism; it was purely mechanical.
    • It was the first stored-program machine — instructions lived on external cards, not in a memory shared with data.
  6. Turing's 1936 paper "On Computable Numbers" contributed…
    • A formal model of computation (the Turing machine) and proofs of its fundamental limits — what can and cannot be computed.
    • The first working electronic computer — "Turing machines are physical" misconception; the machine is a mathematical abstraction.
    • The first programming language — confuses a model of computation with a notation for programs.
    • The stored-program design of EDVAC — that's von Neumann 1945 — though it realizes Turing's universal machine, a nice discussion link.
  7. The Zuse Z3 (1941) is credited as…
    • The first working programmable, automatic, digital computer (2,400 relays, binary floating point, program on punched film).
    • The first electronic computer — relays, not vacuum tubes — probes the electronic (ABC/ENIAC) vs electromechanical distinction.
    • The first stored-program computer — its program stayed on external film; it couldn't even branch.
    • A mechanical calculator that could not be programmed — misses the very property that makes Z3 historic.
  8. ENIAC (1945) was originally built to…
    • Compute artillery firing tables for the US Army.
    • Tabulate the US census — confuses ENIAC with Hollerith's 1890 tabulator.
    • Break enemy codes — confuses ENIAC with Bletchley Park's Colossus.
    • Calculate Moon-landing trajectories — anachronism — two decades early.
  9. The stored-program concept (von Neumann, 1945) says…
    • Instructions and data live in the same memory — so programs can be loaded, modified and even treated as data.
    • Programs are stored permanently on a hard disk — confuses the memory model with persistent storage.
    • Instructions sit in a separate read-only memory from data — that's the Harvard-style split — exactly what stored-program is not; echoes ../../sim/harvard.html.
    • The CPU keeps a copy of instructions in a cache — a modern organization detail mistaken for the founding architectural idea.
  10. Moore's Law (1965) observed that transistor counts double roughly every…
    • 2 years.
    • 6 months — exponential enthusiasm — overshoots the actual cadence.
    • 10 years — undershoots; misses why the effect compounds so dramatically.
    • Clock speed doubles every 2 years — count vs speed confusion — clocks plateaued in the early 2000s while counts kept doubling.
  11. The RISC philosophy is…
    • Few simple instructions, each ideally completing in a single cycle, enabling deep pipelining and compiler optimization.
    • Provide as many powerful, complex instructions as possible — that's CISC, verbatim.
    • Reduce the number of registers to save silicon — misreads "reduced" — RISC typically has more registers.
    • Accept slower chips in exchange for lower cost — "simple = slow" fallacy; simplicity is what makes pipelining fast.
  12. Edge computing means…
    • Processing data near its sources (sensors, devices) for low latency — key to 5G and IoT.
    • Always sending data to a central cloud for processing — the exact opposite; probes whether "edge" was understood at all.
    • Computation at the physical edge of the chip die — plausible-sounding literal reading of "edge".
    • The newest, cutting-edge CPU generation — marketing-word confusion ("edge" = "leading edge").

Group task cards (one line each)

Analytical Engine

Run the preset program through Mill and Store; report which modern component each is, and what a "loop" physically was.

Turing Machine

Run the preset tape to the halt state; report what the machine can't ever tell you about another program.

ABC

Solve the preset linear system; report the one thing this fully electronic machine could NOT do (be reprogrammed).

Z3

Step the preset punched-film program through the relays; report why "no branching" made some programs impossible.

Harvard Mark I

Feed the preset paper-tape table job; report what "Harvard architecture" means about where the program lives.

ENIAC

Rewire the plugboard to the preset firing-table setup; report how long "loading a new program" took and who did that job.

4 · Common misconceptions — expect these, plant them if nobody bites

"ENIAC was the first computer."

It was the first general-purpose electronic one. ABC was electronic but not programmable; Z3 was programmable but not electronic. Great discussion bait — put all three on screen and let the class fight over the definition of "first".

"Moore's Law is physics."

It's an economic observation about industry cadence, not a law of nature — which is exactly why it can (and did) bend. Pair with moore.html's actual-vs-predicted curve.

"RISC lost."

Students see x86 everywhere and assume CISC won. Modern x86 chips are RISC cores wearing a CISC front-end, and ARM (RISC) runs nearly every phone. Both camps claim victory; the decoder is the peace treaty.

"Architecture = hardware."

Architecture is the programmer-visible contract (ISA, memory model, I/O); organization is the physical realization. Same architecture, wildly different organizations — that's how your old binaries still run.

"Turing machines are physical."

The 1936 machine is a mathematical abstraction for reasoning about computability and its limits. Turing never built one; the simulator on turing-machine.html is a visualization of an idea, not a replica.

"Lovelace merely assisted Babbage."

Note G (1843) contains the first published program, and her writing anticipates computing beyond numbers — music, symbols. Babbage designed the machine; Lovelace saw what it meant.
