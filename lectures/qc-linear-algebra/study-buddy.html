A Socratic tutor that lives inside this page and knows the whole lecture. It runs on your own free Mistral API key — stored only in this browser, sent only to Mistral. Ask it anything about complex numbers, kets, operators, eigen-stuff… it will answer with hints, not spoilers.

One-minute setup

This page has no server — the tutor talks straight from your browser to Mistral's API, so it needs a key of your own. The free tier is more than enough for study sessions.

  1. Create a free account at console.mistral.ai (choose the free “Experiment” tier).
  2. In the console, open API Keys → Create new key.
  3. Paste the key below and hit Save key.

Where does the key go? It is stored only in this browser (localStorage key qcla-mistral-key) and sent only to api.mistral.ai when you chat. It never touches any other server — this page doesn't have one. You can make it forget the key at any time with the “Forget key” button. One honest caveat: avoid saving it on shared or public computers — anyone using this browser profile could read it.

Why won't it just tell me the answer?

The buddy is deliberately Socratic — it answers questions with guiding questions and gives the next hint, never the full solution to an exercise. If you want straight answers, any chatbot will happily oblige. But the struggle-with-a-hint is exactly where the skill grows: retrieval plus a nudge beats a copied answer every time.

Your key = your usage

Because the key is yours, the traffic is yours: this page never sees anyone else's conversations, and nobody sees yours. The free tier is plenty for study sessions — a whole evening of tutoring costs a tiny slice of the free quota. If it ever rate-limits you, wait a few seconds and carry on.
