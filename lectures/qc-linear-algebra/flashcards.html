Retrieval beats rereading

Notice the little effort right before you flip — that reach into memory is where learning actually happens. Rereading the lecture feels smooth because recognition is easy; recalling ⟨u|v⟩ from a blank card is hard, and that difficulty is precisely what writes the definition in. Always guess before you peek.

The boxes are honest

A card you've "got" twice still comes back, just more slowly — box 2 every other session, box 3 every fourth. That's not the system distrusting you; it's the system knowing that forgetting is the default. Each return visit, spaced a bit wider, is what turns A = Σλⱼ|j⟩⟨j| from a phrase you recognize into one you own.
