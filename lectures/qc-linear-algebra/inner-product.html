Live readout — bra times ket

⟨u|v⟩ = 00 00 = 0
bra ⟨u| is the (conjugate-)transposed row, 1×2  ·  ket |v⟩ is the column, 2×1  →  (1×2)(2×1) = 1×1 : a single number.
‖u‖ = √⟨u|u⟩ = 0   ‖v‖ = 0
⟨u|v⟩ = ‖u‖ ‖v‖ cos φ = 0 × 0 × cos 0° = 0
Orthonormal check — Gram matrix  ⟨vᵢ|vⱼ⟩ = 1001 = δᵢⱼ  ✓ orthonormal set
Kronecker delta: δᵢⱼ = 1 when i = j (each vector has unit norm), 0 when i ≠ j (mutually orthogonal).
Everything on this page is real, so conjugation does nothing and ⟨u|v⟩ = ⟨v|u⟩. In ℂⁿ the bra takes the conjugate transpose (the dagger †), and the symmetry becomes ⟨u|v⟩ = ⟨v|u⟩* — swap the slots, conjugate the answer. That twist is what keeps ⟨u|u⟩ real and ≥ 0, so norms still make sense.

Number vs. matrix — ⟨u|v⟩ vs. |u⟩⟨v|

Inner product ⟨u|v⟩  (1×2)(2×1) = 1×1

00 00 =0
Row times column collapses everything to one number — the overlap.

Outer product |u⟩⟨v|  (2×1)(1×2) = 2×2

00 00 = 0000
Column times row blows up into a whole matrix — an operator.
Σⱼ |j⟩⟨j| :  |u⟩⟨u| + |v⟩⟨v| = 1000 + 0001 = 1001 = I  ✓ completeness
With |u⟩ = |0⟩ = e₁ and |v⟩ = |1⟩ = e₂, the projectors onto each basis direction sum to the identity: the basis misses nothing. Nudge either vector and watch the sum drift away from I.

A same-direction detector

Notice how the meter reads +1 when the unit vectors point the same way, 0 at a right angle, and −1 when they oppose. The inner product doesn’t care about clutter — it asks one question: “how much do you two agree in direction?” The green projection is that answer made visible.

Bra = measuring device, ket = state

Think of |v⟩ as a state and ⟨u| as a probe you press against it. ⟨u|v⟩ answers “how much of v lies along u?” In quantum computing that overlap is an amplitude, and |⟨u|v⟩|² is the probability of finding the state |v⟩ in the state |u⟩ when you measure.

Orthonormal bases make coordinates trivial

With an orthonormal basis, the coordinates of any |ψ⟩ are just inner products: aⱼ = ⟨vⱼ|ψ⟩ — no equation solving. That is exactly what the completeness relation Σⱼ |j⟩⟨j| = I encodes: apply it to |ψ⟩ and it hands you Σⱼ ⟨vⱼ|ψ⟩|vⱼ⟩, the state rebuilt from its overlaps.
