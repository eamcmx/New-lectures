Spectral Decomposition — operators, taken apart

Every real symmetric (normal) matrix is just a weighted sum of projectors: A = λ₁|v₁⟩⟨v₁| + λ₂|v₂⟩⟨v₂|. Notice what does not move: the blue and yellow eigen-directions. A function of an operator only touches the eigenvalues — never the eigenvectors.

Directions + amounts = the whole operator

A normal operator is fully described by which directions it acts along (eigenvectors) and how much it stretches each (eigenvalues). The spectral decomposition A = Σⱼ λⱼ|j⟩⟨j| is exactly that sentence, written in matrices. And this diagonal form exists precisely when A is normal (AA† = A†A) — no normality, no orthonormal eigenbasis.

Projectors that tile the space

Each |j⟩⟨j| is a projector onto one eigen-direction — toggle "term 1 only" and watch the whole plane get squashed onto a single line. The completeness relation Σⱼ|j⟩⟨j| = I says these projectors tile the whole space: nothing is lost, every vector is exactly the sum of its shadows.

This is how quantum time evolution is computed

f(A) = Σⱼ f(λⱼ)|j⟩⟨j| turns hard matrix functions into arithmetic on numbers. In quantum mechanics the evolution operator e^{−iHt} is computed exactly this way: diagonalize the Hamiltonian H once, and then any function of it — for any time t — comes for free.
