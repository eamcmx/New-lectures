⇄ Von Neumann vs Harvard — the same program on both 🧮 Von Neumann sim 🧠 Harvard sim
One program, two architectures. Both machines run the identical instruction set and compute the identical answer — what differs is how they reach memory. The Von Neumann machine has one memory and one bus: every instruction fetch and every data access take turns on the same wire (the von Neumann bottleneck). The Harvard machine has separate program and data memories on separate buses: a fetch and a data access happen at the same time. Press Step to run one instruction on both and watch the buses; the bus-cycle counters show the gap grow.
