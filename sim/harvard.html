A Harvard machine has TWO separate memories and TWO separate buses. The program memory (instructions) is reached over the instruction bus; the data memory (your X, Y, Z, W, T… cells) over the data bus. Because they are independent, fetching an instruction and accessing data never compete for the same wires — so they can overlap. That is the opposite of the Von Neumann machine, where one shared bus forces instructions and data to take turns (the von Neumann bottleneck). The STC89C52 / 8051 you program on the real board in T4–T7 is a Harvard machine: program in ROM, data in RAM. Same instruction set as our Von Neumann sim, so you can run the very same program here and watch the difference.

Von Neumann vs Harvard

Von Neumann
ONE memory holds instructions and data. ONE bus. A fetch and a data access must take turns → the bottleneck.
Harvard
TWO memories (program + data), TWO buses. A fetch (instruction bus) and a data access (data bus) are independent → they can overlap.
