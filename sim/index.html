CPU Simulators

Interactive single-accumulator machines for the Computer Systems Architecture course — watch the fetch–decode–execute–store cycle run, one T-state at a time. The same instruction set runs on both architectures, so you can see exactly what the architecture changes.

🧮
Von Neumann simulator (vnmsim)
One memory, one bus. The machine used in CW1. Compile, single-step through the T-states, watch the ALU, save your programs.
🧠
Harvard simulator
Separate program and data memories on separate buses — like the 8051 / STC89C52 on the bench. See the instruction bus and data bus light up independently.
⇄
Von Neumann ⇄ Harvard — side by side
Run one program on both machines at once. The bus-cycle counters make the von Neumann bottleneck visible: Harvard does the same work in fewer cycles because a fetch and a data access never compete for the same bus.

Transport Telecommunication Institute · Computer Systems Architecture · instruction set: LOD STO ADD SUB MUL DIV JMZ JMP NOP HLT. Built on the vnmsim model.
