🧮 vnmsim — Von Neumann Machine Simulator · see inside the CPU · CW1🧠 Harvard sim⇄ compare
Watch what happens inside the CPU, one T-state at a time. The machine runs the fetch–decode–execute–store cycle across timing states τ1, τ2, τ3… — Step advances one T-state; Run plays them all continuously (the speed slider sets the pace). FETCH: MAR←PC → address bus → MDR←M[PC] → IR←MDR, PC++. EXECUTE: operands flow into the ALU (which shows the two values and the operation symbol). STORE: the result is written to ACC or a memory cell. Jumps target a line number (counting comments/blanks) — no labels. Result conventionally in cell Z. Mirrors the real vnmsim.
